**Welcome to _Inside Infra_ for September, 2026**

## Roundtable

September's Roundtable featured a report on the current state of the **Contingent Approval Platform (CAP)**. 

CAP provides a single, uniform workflow for establishing proof of consensus in a project for a given action, whether this is a social/manual thing or an automated task that requires approval.

A demo version is up and running at <a href="https://cap-test.apache.org" target="_blank">cap-test.apache.org</a>, and <a href="https://cap-test.apache.org/#/about" target="_blank">cap-test.apache.org/#/about</a> has documentation and the tool's rationale in great detail.

**Note:** the October Roundtable will be an **in-person** event at Community Over Code Glasgow.

Details about joining one of the online roundtables, and what goes on at one, are here: <a href="https://infra.apache.org/roundtable.html">infra.apache.org/roundtable.html</a>.

## Atlassian migration

Work continues on the migration of our in-house Jira and Confluence Wiki services to their cloud equivalents.

## Improvements to Boxer

Infra released a new version of Boxer in early September. With Boxer, first released in 2022, developers link their GitHub accounts with their ASF credentials, providing them with write access to GitHub.

The immediate upgrades in this release are an improved UI and the new opt-in public teams.

Longer term, Infra is looking into multitenancy wherein each project gets their own organization within the ASF enterprise space. This would enable certain security features that have until now been root-only, as well as build quotas and better app isolation.

## Improvements to ASF mail delivery

Infra has identified some DKIM-related problems related to downstream handling of DKIM policies. We are testing a workaround that we expect to deploy by the end of September.
