# GitHub Apps

GitHub Apps have status similar to a human GitHub user. They can open issues, comment on pull requests, and manage projects. Depending on how they are structured, they can also do things outside of GitHub, like posting a note in a Slack channel when someone opens a GitHub issue.

Because of GitHub Apps' potential to act autonomously, The ASF looks carefully at a project request to add one. There are certain options that the ASF almost never grants to a GitHub app because they would give the app too much latitude to access data and to change things in repositories or even in the structure of the ASF's presence on Git.

## Adding a GitHub App to the ASF on GitHub

Infra has established guidance for requesting the addition of a GitHub App to the ASF's GitHub presence. The document provides definitions, caution areas, and questions the project needs to answer when making its request: <a href="https://cwiki.apache.org/confluence/spaces/INFRA/pages/444334693/Adding+a+GitHub+App+to+the+ASF+GitHub+Organization" target="_blank">Adding a GitHub App to the ASF GitHub Organization</a>.
