_More definitions coming_

- **checksum** - (per the Mirriam-Webster online dictonary) "a sum derived from the bits of a segment of computer data that is calculated before and after transmission or storage to assure that the data is free from errors or tampering."
- **CTR** - "commit, then review" - Projects following this pattern do not require a second committer to review code before it is committed to the repository. Such projects have a system for reviewing the updated code after each commit to make sure it functions as intended.
- **hashtag** (or 'hash') - a clickable keyword or phrase prefixed with the hash symbol (#) that categorizes social media content related to software, making it easier for users to discover posts about specific topics. Common examples include #software, #softwareengineer, #coding, and #tech.
- **lint checking** - a system for checking a file for errors or omissions that should be corrected before the file is added to the repository. There are different lint checkers for reviewing code and documentation, and for checking that the code follows the standards of the coding language in which it is written
- **rebase** - Actions to keep the code in your branch in sync with the code in the trunk or release branch.
- **roundtable** - In 2022, the Infrastructure team initiated monthly discussions of infrastructure issues. They are generally online, and in-person as an event at ASF Community Over Code events. Other ASF groups are considering offering their own monthly meetings under the 'roundtable' banner. 
- **RTC** - "review, then commit" - Projects following this pattern require a second committer to review code before it is accepted into the repository, to confirm that it contains no obvious errors and is likely to do what it is intended to do.
- **SBOM** - 'Software Bill of Materials', a nested inventory of the ingredients that make up a software component. 
- **signature** - A digital signature validates the identity of the software author or publisher and verifies that the file it is applied to has not been altered or tampered with since it was signed.
